# Appointment Automation

## Overview

This project is a no-code AI automation workflow for managing appointment data.

## Workflow

1. A user submits an appointment request through a **Google Form**.
2. The submitted appointment data is automatically stored in **Google Sheets**.
3. **Make** detects the new appointment data and runs the automation.
4. The workflow processes the appointment information and performs the configured automated action.

## Technologies

* Google Forms
* Google Sheets
* Make (Make.com)
* AI automation

## Purpose

The automation reduces manual appointment handling by connecting a real form submission to an automated workflow.

## Demo

The project demonstrates the complete workflow from Google Form submission to automated processing through Make.
